# Nexora Life Industries Website

A responsive static website for Nexora Life Industries.

## Products currently configured

- 500 ML PET — 12 bottles/carton — Rs. 360
- 1.5 Liter PET — 6 bottles/carton — Rs. 300
- 6 Liter Bottle — 1 bottle — Rs. 100
- 19 Liter Can — 1 can — Rs. 600
- 1 Liter is intentionally removed.

## Before publishing

1. Open `script.js`.
2. Find `WHATSAPP_NUMBER`.
3. Replace `923XXXXXXXXX` with the business WhatsApp number in international format.
4. Upload `index.html`, `style.css`, and `script.js` to GitHub.
5. Enable GitHub Pages or connect the repository to Netlify.

## Product images

The current version uses lightweight CSS/SVG-style product illustrations, so the website works immediately without external image hosting. Your original Nexora Life bottle images can be added later without changing the order system.
